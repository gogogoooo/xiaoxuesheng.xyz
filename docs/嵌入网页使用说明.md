# 日常嵌入网页目录

## 用途和地址

`public/embed/` 用于托管日常零散的独立网页，供其他文档通过链接或 iframe 嵌入。

新增页面采用以下结构；`随机标识` 请替换为实际生成的随机字符串：

```text
public/embed/随机标识/
├── index.html
└── assets/
    ├── 图片.png
    └── 样式.css
```

发布后的地址为 `https://xiaoxuesheng.xyz/embed/随机标识/`。Cloudflare Pages 可能将带 `index.html` 的地址规范化为目录地址；两者指向同一份页面，并非不同的访问权限。

## 新增流程

1. 在网站工作目录的 PowerShell 中运行 `[guid]::NewGuid().ToString('N')`，得到 32 位随机标识。每个页面使用不同标识，不使用连续编号或可猜的标题。
2. 创建 `public/embed/随机标识/`，将网页命名为 `index.html`。可以参考 `docs/templates/embed-page.html`；模板本身不会发布。
3. 图片、CSS 和脚本放在该页面自己的目录中，用 `./assets/图片.png` 这样的相对路径引用。
4. 页面保持独立，不引用网站首页导航，也不添加“上一页”“下一页”等其他嵌入页链接。
5. 提交并推送到生产 `main` 后，Cloudflare Pages 自动构建发布。只推送开发分支不会更新生产网站。
6. 将完整网址粘贴到支持嵌入网页的文档工具中，或使用下面的 iframe。

```html
<iframe
  src="https://xiaoxuesheng.xyz/embed/随机标识/"
  title="页面说明"
  width="100%"
  height="720"
  loading="lazy"
  referrerpolicy="no-referrer"
  style="border:0"
></iframe>
```

外部文档工具是否允许 iframe，取决于该工具本身。站点没有为此目录设置 `X-Frame-Options` 或限制 `frame-ancestors`。

## 维护约定

- 不加入首页、导航、作品卡片、汇报材料目录或站点地图。
- 不创建 `public/embed/index.html` 或包含页面清单的公开文件；`/embed/` 与不存在的子路径应返回 404，不展示目录列表。
- `public/embed/404.html` 是无链接的目录专用错误页，不是目录入口。
- `public/_headers` 对该目录的网页和附件统一添加 `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex` 和 `Referrer-Policy: no-referrer`。HTML 同时保留 robots 和 referrer 元标签。
- 不在 `robots.txt` 公开列出具体页面路径。搜索引擎需要抓到页面才能读取 `noindex`，不要同时用 `Disallow` 阻止读取这些响应头。
- 原地址更新内容时覆盖原目录文件，保持已嵌入的链接有效。
- 禁止收录和随机地址只降低被发现的机会，不是身份验证。收到链接的人可以访问和转发，也可能经由外部文档暴露；需要保密的内容应另加鉴权。
