# 数字作品展厅首页设计

## 目标

将当前偏文字目录的首页重设为“数字作品展厅”：首页是个人作品的有记忆点入口，同时保持三大板块和后续栏目扩展的清晰结构。

## 视觉方向

- 背景使用深石墨色与轻微颗粒质感，文字使用暖白，避免企业官网或文档页的单薄感。
- 首屏是一张展厅封面：左侧是简短的站点定位，右侧是抽象、非具象的作品轨道和编号，形成明确的视觉焦点。
- 三张入口改为不同尺度的“展品卡”：不再平均分栏；电路实验室为最大主卡，小工具与网页作品为辅助卡。
- 卡片只保留实用信息：栏目编号、标题、简介、项目状态和进入动作；用强烈的色块、材质和图形建立区分。
- 动效仅用于卡片进入、悬停与焦点反馈；尊重 `prefers-reduced-motion`。

## 页面结构

```text
站点顶栏：标识、三个栏目导航
首屏：站点编号、标题、简短定位、抽象展厅主视觉
作品入口：三张不等宽展品卡
页脚：站点署名、域名、版权
```

## 扩展方式

继续使用 `lib/site-content.ts` 的 `siteSections` 数据数组。新增栏目仅增加一条记录；卡片布局由 CSS 网格的首项强调规则自动适配，不需要重写首页组件。

## 响应式与可访问性

- 宽屏：第一张卡占两列，两张辅助卡纵向排列或占一列。
- 窄屏：首屏主视觉缩小，三张卡恢复单列，保持触控面积。
- 卡片链接、导航和焦点状态保持键盘可访问。
- 正文不小于 16px，辅助信息不小于 12px。

## 验收

- 首页在桌面与手机宽度下无横向滚动，三张卡均可进入对应页面。
- 源码仍通过入口数据契约测试、原电路测试和生产构建。
- 视觉上不以大段文字或平均卡片堆叠作为首要表现；首屏与三张卡具备明显层级。
