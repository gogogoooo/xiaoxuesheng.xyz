# NOBOOK 风格电磁虚拟实验室设计

## 目标与范围

在现有个人网站的 `/lab/circuits/little-circuit` 路由中，将当前基础电路桌面逐步扩展为开放式电磁实验台。它必须支持器材自由摆放、旋转、接线、保存和实时仿真；预设实验只是把器材摆好的快捷入口，不限制继续自由操作。

本项目保持纯前端静态站点：不新建 Workers，不依赖后端，不修改 Cloudflare 或 DNS。实验数据仅保存于浏览器本地，可导出和导入 JSON。

第一期交付范围是：开放电磁工作台、直流电路求解与仪表、条形磁铁/通电导线/螺线管、小磁针和磁感线。电动机、感应、静电与实验报告在后续阶段实现。

## 技术方案

采用 PixiJS 作为高频画布渲染和命中检测层，React 保留页面框架、工具栏、器材库与属性面板。物理计算放在独立的 TypeScript 模块中，不嵌入渲染组件。

电路使用基尔霍夫电流定律和欧姆定律的线性直流求解。每次连线、删除、开关或参数变化都会重建拓扑并计算节点电压、支路电流和仪表读数。短路、开路、超量程由求解结果产生提示。

磁场使用可叠加的解析近似：条形磁铁按二维磁偶极子、直导线按毕奥-萨伐尔定律的平面近似、螺线管按有限线圈轴向近似。小磁针沿局部合磁场方向旋转；磁感线从采样的磁场向量积分得到；铁屑密度和曲别针吸附数由磁场强度驱动。

导体受力和电磁感应分别由 `F = I L × B` 与 `ε = -dΦ/dt` 计算。器材实际运动、吸附和磁铁相互作用使用明确的教学近似力模型，不采用预录动画；任何方向、距离、电流或匝数改变都会进入下一帧计算。

## 模块边界

- `lib/electromagnet/schema.ts`：器材、端子、参数、场景与序列化类型。
- `lib/electromagnet/topology.ts`：由导线和端子构建电路拓扑，诊断断路和非法连线。
- `lib/electromagnet/dc-solver.ts`：求解电阻、电池、开关、滑动变阻器及电表支路。
- `lib/electromagnet/field.ts`：计算任意画布点的合磁场与磁通量。
- `lib/electromagnet/simulation.ts`：统一运行/暂停/重置、仪表响应、受力、感应和教学近似运动。
- `lib/electromagnet/presets.ts`：六个经典实验的可编辑场景数据。
- `app/lab/circuits/little-circuit/*`：React 工具栏、属性面板、底部数据面板与 Pixi 工作台。
- `tests/electromagnet/*.test.mjs`：无渲染的物理、拓扑、序列化与预设回归测试。

渲染层只读取场景和仿真快照，并把用户操作转成明确的场景命令。这样渲染技术替换、增加器材或修改计算模型不会改变存档格式。

## 交互与数据流

1. 用户从右侧器材库点击或拖拽一个器材到工作台。
2. 工作台生成有稳定 ID 的器材实例、端子和默认参数；选中后显示属性与旋转操作。
3. 用户拖拽端子创建红色导线；命中半径内的目标端子自动吸附，非法连接直接提示。
4. 场景命令进入撤销/重做栈；随后拓扑、直流求解和磁场计算生成最新仿真快照。
5. PixiJS 在每帧读取该快照，绘制器材、导线、磁感线、磁针、铁屑、仪表指针和受力运动。
6. 保存按钮写入 `localStorage`；导出按钮下载版本化 JSON；导入先校验模式与数量上限，再替换当前场景。

## 分期交付

### 阶段 0：基础架构

建立电磁器材模式、场景版本、命令历史、序列化校验与独立测试目录；保留当前基础电路页面路由和站点其他栏目。

### 阶段 1：开放实验台

引入 PixiJS 工作台和右侧分类器材库。实现平移、缩放、拖放、旋转、选择、删除、端子吸附、红色导线、撤销/重做、运行/暂停/重置、JSON 保存读取和截图。

### 阶段 2：电路与仪表

扩展现有直流求解器，加入可调电源、固定电阻、滑动变阻器、电流表、电压表、灵敏电流计。底部面板显示电流、电压和开路/短路/超量程反馈。

### 阶段 3：磁场核心

实现条形磁铁、U 型磁铁、通电直导线、通电螺线管、电磁铁、小磁针和铁屑玻璃板；显示可切换的淡蓝色磁感线与磁针方向。

### 阶段 4：电磁铁和磁场受力

实现线圈匝数、电流与磁场强度关系；以阈值加连续强度模型控制曲别针吸附数量；实现蹄形磁铁、导轨和通电导体棒的洛伦兹力方向与运动。

### 阶段 5：电磁感应

实现可移动导体棒、磁通量变化、反向电流和灵敏电流计双向偏转；静止时读数归零。

### 阶段 6：预设与完善

增加奥斯特、螺线管、电磁铁强弱、磁场受力、电磁感应、条形磁铁磁感线六个可编辑预设；完成触摸操作、离线缓存、性能监控、知识提示和无障碍键盘操作。

## 验收标准

- 任意预设加载后都可继续自由添加、移动、旋转、连线和删除器材。
- 电流、电压、仪表指针、磁针、磁感线、感应方向和受力方向由实时计算结果驱动。
- 改变电源极性、开关、磁极方向、匝数、距离或运动方向后，现象在下一仿真帧相应变化。
- 保存后重新加载保持器材、参数、导线、视图和运行状态；非法或超限 JSON 被拒绝且不破坏现有场景。
- PC 鼠标优先，平板触摸可用；静态构建成功，现有首页、实验室目录和其他栏目回归测试通过。

## 风险与约束

- 不把完整三维电磁有限元计算带入浏览器。使用初中教学足够、连续且参数驱动的二维近似，并在知识提示中说明模型边界。
- 大量磁感线和铁屑仅在运行时按可视区域采样；低性能设备降低采样密度而不改变物理计算。
- 直流线性网络是第一期电路范围；交流、二极管、复杂非线性元件不纳入本阶段。
- 每个阶段必须先为新物理规则写失败测试，再实现；提交前运行 `node tests/circuit.test.mjs`、新增电磁测试、`node tests/site-content.test.mjs` 和 `pnpm build`。
