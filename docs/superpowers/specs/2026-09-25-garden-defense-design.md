# 花园防线设计

在个人网站“小程序 · Demo · 工具”栏目增加独立的离线塔防小游戏。它保留经典植物塔防的核心节奏：在 5×9 草坪上收集阳光、种植植物、抵御从右侧进入的僵尸，通关固定的三波进攻。所有形象、视觉与文字由本站原创绘制，不使用原游戏素材。

## 玩法

- 起始阳光 150。点击天降阳光或向日花生产的阳光获得资源。
- 四种植物：豆豆射手（100，直线射击）、向日花（50，周期产阳光）、坚果盾（75，高血量阻挡）、爆爆果（150，短延迟范围爆炸）。每种有独立冷却。
- 选择卡片后点击空格种植；铲子可移除；数字键 1–4、空格暂停、R 重开。
- 僵尸沿所在行向左前进，接触植物时攻击。普通僵尸和戴桶僵尸血量不同。每行一辆割草小车，首次越线时救场；再次越线失败。
- 三波进攻完成且场上无僵尸即胜利。暂停后游戏逻辑停止；胜负后可重开。

## 架构与交互

`public/games/garden-defense/` 全部独立：`index.html`、`style.css`、`rules.js`、`game.js`。普通脚本相对加载，双击 HTML 即可离线运行。`rules.js` 不依赖 DOM，负责网格、资源、冷却、阳光、植物、弹丸、僵尸、割草机和波次；`game.js` 负责 Canvas 绘制、输入和可视状态。页面有桌面与手机布局；Canvas 根据屏幕缩放，点击/触屏都可操作。

站点 `/apps` 追加游戏卡片，链接 `/games/garden-defense/`。不新增服务端、第三方图片、字体、音频或联网请求。

## 验证

先写规则测试并确认缺失时失败，再实现规则使之通过。覆盖资源消耗、非法种植、射击与伤害、产阳光、铲除、割草机、胜负与暂停。构建网站静态包，确认独立游戏目录进入 `dist/client`，通过本地 HTTP 打开检查。
