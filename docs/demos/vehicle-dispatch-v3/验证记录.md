覆盖内容：

- 独立离线包、手机端外壳、无外部网络依赖、无浏览器持久化。
- 八类角色和用车、加油、维修三大模块页面。
- 普通、出差、特殊车辆三类申请审批路线。
- 处长兼主任时的下一审批节点自动通过及双节点留痕。
- 司机班按车型派车、跨车型调整原因、前后照片、归还车况异常处理。
- 加油登记时间范围与车管中心补登。
- 维修 5000 元审批边界、最终金额变化后的重新审核、处长自动审批。
- 车辆全周期台账聚合。
- 车辆导入预检、按车牌新增/更新且不删除。
- 部门用车汇总导出。
- 八类角色最小权限矩阵、业务入口过滤和直接路由拦截。
- 消息按当前身份隔离，避免多角色账号看到其他身份待办。
- “车辆中心处长”名称统一。
- 用车流程按普通、出差、特殊车辆类型生成标准节点，并与实际操作记录分开显示。
- 系统管理员维护“部门—固定负责人”绑定；候选人限本部门在职人员，并自动授予负责人角色。
- 部门负责人按绑定部门过滤列表、详情和审批操作，跨部门用车单不可查看、不可处理。
- 系统管理员可新增部门；安全删除会拦截仍有关联人员或历史用车单的部门。
- 维修单按金额条件生成标准流程，并与实际操作记录分开展示；两条演示维修记录已补齐关键处理节点。

## 现场演示前建议

1. 使用目标电脑打开 `index.html`，确认浏览器允许下载 CSV 文件。
2. 推荐先用 `wangmin` 登录，检查八类身份均可切换。
3. 每轮完整演示前点击“我的 → 恢复初始演示数据”。
4. 浏览器缩放保持 100%，手机窗口宽度按 414px 设计。
