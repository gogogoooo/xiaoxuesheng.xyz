# 音视频转换工具：第一版页面设计

此文保留设计阶段记录。2026-10-27 已接入真实本机转换，当前功能与验证范围见[使用与维护](./音视频转换工具使用与维护.md)。

## 已确认的方向

- 不增加算力服务器，未来转换使用访问者浏览器的 CPU 和内存。
- 以电脑浏览器为主，单文件严格小于 1,000,000,000 字节，每次一个文件。
- 视频输入覆盖 FLV、MP4、MOV、MKV、WebM、AVI，实际转换范围取决于引擎支持的编码。
- 输出优先 MP4、WebM；音频输出 MP3、WAV、AAC、FLAC。
- 优先快速转封装；不兼容或需要调整画质、分辨率时再重新编码。
- 文件大小上限不代表浏览器可稳定处理上限，较大文件需提示内存要求。

## 本次交付范围

用户当前请求“开始设计网页”，本次先交付可操作的设计预览：

- 目录：`public/tools/media-converter/`。
- 路径：`/tools/media-converter/`。
- 页面由 `index.html`、`styles.css`、`app.js` 构成，独立维护，不依赖框架和服务器接口。
- 可选择、拖入、更换和移除本地文件，校验类型、空文件与大小上限。
- 可切换视频 / 音频、输出格式、处理方式、画质和分辨率。
- 浏览器可识别时读取原文件时长，无法读取时如实显示。
- 另有明确标记的静态状态示例：进行中、已完成和异常。
- 转换按钮暂时禁用，页面明确说明尚未接入真实转换。不会模拟真实转码或提供虚假下载。

## 视觉

暖白纸感背景、石墨色文字、陶土橙强调，浅灰绿色用于本机处理提示。首屏左侧是文件区，右侧是输出设置，手机端上下排列。文件选择与格式设置是页面的主任务，说明和常见问题放在工作区后方。

## 后续接入边界

页面设计已获用户认可。转换执行层的模块、引擎加载、内存策略和实施顺序见[音视频转换工具执行层方案](./音视频转换工具执行层方案.md)。当前代码已接入真实转换，移除了静态示例状态。

接入 ffmpeg.wasm 时应独立维护引擎适配层，处理真实进度、取消、资源释放和输出下载。不要把示例状态当真实进度使用。实际接入前确认引擎资源加载方式、Cloudflare Pages 单资源大小限制、CORS 及多线程所需的跨源隔离；不能把用户视频上传作为默认处理路径。

本次设计阶段不改动小工具栏目入口，不推送生产 `main`，待页面方向确认或用户明确要求接入功能后继续。

## 本地预览与检查

在项目目录先运行 `node scripts/prepare-media-engine.mjs`，再运行 `node scripts/preview-media-converter.mjs`，打开 `http://127.0.0.1:3012/tools/media-converter/`。预览服务只监听本机，仅提供工具目录中的静态资源。

已检查 JavaScript 语法、页面 ID 和 SVG 引用；桌面 1280px 下为双栏，手机 390px 下为单栏且没有横向溢出。本地生成的 1 秒 WAV 样本能够被选择、读取时长并自动切换音频设置；输出名称随格式选择更新。WAV 输出禁用不适用的码率设置，完成与异常示例可切换，页面控制台没有错误。

网站静态构建通过，三个页面资源均进入 `dist/client/tools/media-converter/`。未执行真实音视频转换测试，因为本阶段没有接入转换引擎。
