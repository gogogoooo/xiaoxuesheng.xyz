# 流沙模拟器

独立离线 Canvas 沙盒小游戏。使用原创绘制的卡通方块角色与伪 3D 沙盘，不依赖 Roblox、第三方素材、网络资源或后端。

## 打开方式

双击本文件夹中的 `index.html`。分发时复制整个文件夹，保留 `index.html`、`style.css`、`physics.js`、`game.js` 四个文件的相对位置。网站入口为 `/games/quicksand-simulator/`，在小程序 / Demo / 工具页面可以进入。

## 操作

- WASD / 方向键：按屏幕方向移动；触屏使用左下方向键。
- 左键拖动：绘制流沙。右键拖动：擦除。触屏可以选择擦除工具。
- Alt＋左键 / 中键拖动：旋转视角。或选择视角工具后直接拖动。
- 滚轮 / 缩放滑块：缩放。
- 生成克隆人：启用放置工具，然后点击沙盘任意位置；最多 24 人。
- 暂停：停止人物与粒子模拟，仍可编辑沙盘。
- 重置场景：清空流沙、克隆人、重生计数，让玩家回到出生点。

初始场景有三片示例流沙。绿色十字区域是受保护的出生点，不可涂画。人物完全沉没后隐藏 0.7 秒，再回到安全区；克隆人循环漫游和重生。

## 维护边界

- `physics.js`：网格、材质浮力与阻力、绘制、人物移动、下沉和重生、克隆人漫游。不引用 DOM，便于测试。
- `game.js`：Canvas 正交投影、地面缓存、方块角色、表面波纹、颗粒、相机与输入、面板同步。
- `style.css`：独立页面样式，手机纵向排布和触屏控制。
- `index.html`：中文界面及离线资源入口。使用普通 script 标签，避免 file:// 下 ES module/CORS 限制。

规则是面向沙盒体验的风格化模拟，不是真实流沙物理或户外安全指导。浮力越高，下沉越慢；移动挣扎将下沉速率降至静止时的 68%，但仍可能沉没。走出流沙后逐渐恢复到地面高度。

维护时运行网站仓库根目录的 `node --test tests/quicksand.test.mjs`。游戏静态文件由网站构建复制到 `dist/client/games/quicksand-simulator/`。不要单独部署到其他 Cloudflare 项目。
