# 花园防线

原创画风的离线植物塔防小游戏。双击本文件夹 `index.html` 即可试玩；四个文件 `index.html`、`style.css`、`rules.js`、`game.js` 须放在同一目录。网站中的访问地址是 `/games/garden-defense/`。

先选择植物卡，再点击草坪空格种植。点击场上太阳收集资源；选择小铲子后点击植物即可移走。键盘 1–7 选择植物，空格暂停，R 重来。手机、平板可横向滑动植物栏与草坪，点按种植、收太阳。

植物共七种：豆豆射手、向日花、坚果盾、爆爆果、冰冻射手、地刺、双向射手。冰冻射手减缓敌人脚步；地刺在本格持续造成伤害；双向射手可向左右两侧发射。

点击“游戏设置”可调整每朵阳光 25／50／100／200／500、豆豆射手每轮连发 1／2／4／8／16，以及冰冻射手与双向射手共用的攻击间隔 0.25／0.5／1／1.5／2 秒。默认分别是 25、1、1.5 秒。选择后立即作用于当前游戏；重新开始保留档位，刷新页面恢复默认。

所有角色、图形由 Canvas 代码绘制，不含第三方图片、音乐或网络资源。规则集中于 `rules.js`，页面绘制与操作集中于 `game.js`。修改规则后在仓库根目录运行 `node --test tests/garden-defense.test.mjs tests/garden-defense-expansion.test.mjs`。
